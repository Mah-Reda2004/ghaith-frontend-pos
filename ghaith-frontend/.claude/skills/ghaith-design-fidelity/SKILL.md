# مطابقة تصميم غيث بالظبط (Design Fidelity)

القاعدة الأساسية: **إحنا مش بنصمم، إحنا بننفّذ تصميم موجود بالفعل.** أي
سكيل تاني بيقول "خد قرار تصميمي مميز" (زي `frontend-design`) **ملوش محل هنا**
— كل قرار شكلي اتاخد قبل كده في فيجما. شغلنا إننا نطابقه بدقة، مش نجتهد.

كل الأنماط اللي تحت متأكدة من مراجعة صور فعلية للتصميم. لو الصفحة اللي
بتبنيها مش من ضمن اللي شفناها، طبّق نفس النمط المتكرر (كل صفحات القوائم
بتتبني بنفس الهيكل بالظبط) بدل ما تخترع تخطيط جديد.

## 1. الهيكل العام (كل الصفحات من غيرها استثناء)

- **السايد بار على اليمين دايمًا** (RTL): شعار "غيث" بالبرتقالي أعلى
  السايد بار، تحته قائمة نفيجيشن عمودية بنفس الترتيب دايمًا:
  الرئيسية ← المبيعات ← المنتجات ← التصنيفات ← المخزون ← الموردين ←
  المستخدمين ← المصروفات ← الخصومات ← التقارير.
  آخر عنصر نشط بيتلوّن **بخلفية برتقالي solid كاملة** (مش حدود، مش نص
  برتقالي بس) — ده الفرق البصري الوحيد بين active وباقي العناصر.
- أسفل السايد بار: "chip" باسم المستخدم مع أفاتار دائري، وتحته مباشرة
  رابط "تسجيل الخروج" بالبرتقالي مع أيقونة خروج.
- منطقة المحتوى (يسار السايد بار): عنوان الصفحة الكبير (bold) + سطر وصف
  رمادي تحته مباشرة (فف`.page-subtitle`)، غالبًا معاه في نفس الصف عنصر
  تحكم إضافي (فلتر تاريخ "هذا الشهر" أو زرار "إضافة جديد").
- **Grid rule الصحيحة**: `.app-shell { grid-template-columns:
  var(--sidebar-width) 1fr }` والسايد بار `grid-column: 1`. في RTL عمود
  1 هو أقصى اليمين — ده اللي بيخلي السايد بار يفضل يمين. لو لقيت الكود
  عكس كده (زي الغلطة اللي حصلت أول مرة) صلّحه فورًا، ده أهم باج بصري
  ممكن يحصل.

## 2. كروت الإحصائيات (Stat Cards)

بتظهر في كل صفحة تقريبًا (الرئيسية، المبيعات، المنتجات، المخزون،
الموردين، المستخدمين، الخصومات) بنفس الأنسومبل بالظبط:

- صف من **3 أو 4 كروت** حسب الصفحة، عرض متساوي.
- كل كارت: مربع أيقونة ملوّن أعلى الكارت (لون مختلف حسب دلالة الرقم —
  أحمر/زهري للمصروفات، أخضر للربح، أزرق للعدد، برتقالي للمبيعات)، وممكن
  chip دلتا صغير جنبه (سهم لأعلى أخضر / لأسفل أحمر + نسبة %).
- تحت الأيقونة: **رقم كبير bold** (`--fs-2xl`)، وتحته مباشرة label رمادي
  صغير بيوصف الرقم. كل النص متجاذب لليمين (align-end في RTL).
- لو الكارت بيمثل تحذير (زي "منتجات منخفضة المخزون: 24") الأيقونة نفسها
  بتبقى برتقالي/تحذيري مع مثلث تحذير، مش أيقونة عادية.

## 3. صفحات القوائم (Products / Categories / Suppliers / Users / Sales)

نفس الهيكل بالظبط في كل الصفحات دي:

```
[زرار "+ إضافة جديد" برتقالي، أعلى يمين منطقة المحتوى]
[صف كروت إحصائية]
[Toolbar: فلتر حالة (dropdown) + فلتر نوع/تصنيف (dropdown) + خانة بحث
 بأيقونة عدسة، كله في صف واحد]
[كارت الجدول: رأس أعمدة رمادي، صفوف بيانات، عمود "الإجراءات" أقصى
 اليمين فيه زرار تعديل (قلم) وزرار حذف (سلة حمراء)]
[Footer الجدول: أرقام صفحات (Pagination) على اليمين + نص
 "عرض 1 إلى X من Y" على الشمال]
```

- خانة البحث دايمًا آخر عنصر في التولبار (أقصى الشمال بصريًا لأنها أطول
  عنصر، RTL) بـ placeholder زي "البحث عن منتج، رمز SKU..."
- أعمدة الجدول بترتيب RTL: اسم العنصر (أول عمود يمين) → بيانات وسط →
  حالة (badge) → إجراءات (شمال الجدول تمامًا).
- الـ badge بتاع الحالة: نقطة صغيرة ملوّنة + نص، خلفية شفافة بلون الحالة
  (`نشط`=أخضر, `غير نشط`=رمادي, `حرج`=أحمر, `منخفض`=برتقالي/تحذيري,
  `متوفر`=أخضر, `نفد تمامًا`=أحمر).

## 4. المودالز (إضافة / تعديل)

- Overlay غامق شفاف (65%) خلف المودال.
- رأس المودال: أيقونة صغيرة + عنوان يمين، زرار إغلاق X أقصى الشمال.
- الحقول full-width عمودية، label رمادي صغير فوق كل حقل.
- صف الأزرار في الآخر: **الزرار البرتقالي (الإجراء الأساسي زي "حفظ
  الفئة") بيتحط في أقصى يسار الصف، وزرار "إلغاء" (outline) بجنبه ناحية
  اليمين**. اتأكد من الترتيب ده بالظبط، معكوس عن التوقع في LTR.
- نسبة الخصم/الحقول الرقمية بتتعرض بعلامة % أو وحدة العملة جنب الرقم.

## 5. مودال/كارت النجاح (بعد الإضافة)

يظهر بعد أي عملية إضافة ناجحة (منتج، مستخدم، خصم):

- دائرة خضراء فيها علامة ✓ في النص العلوي.
- عنوان bold "تمت الإضافة بنجاح" / "تم التحديث بنجاح".
- جملة وصف رمادية تحته.
- كارت تفاصيل ملخّص (زي: اسم العنصر + صورة/أيقونة + الحالة + كود/SKU +
  تاريخ الإضافة) بصفوف label/value.
- زرارين تحت بعض: الأول برتقالي solid ("إضافة منتج آخر" — يكرر نفس
  الفعل)، تحته زرار outline ("العودة للقائمة" / "العودة للمخزون").
- ممكن يبقى فيه رابط ghost تالت تحتهم (زي "طباعة بباركود المنتج").

## 6. حالات الفراغ والخطأ (Empty / Error States)

بتظهر بديل الجدول/المحتوى وقت مفيش بيانات أو حصل خطأ اتصال:

- كارت مربع منفصل، أيقونة دائرية ملوّنة أعلاه (تحذير أحمر للخطأ، أيقونة
  محايدة رمادية للفراغ، ✓ أخضر للنجاح).
- عنوان bold واضح ("تعذّر تحميل المبيعات" / "لا توجد عمليات بيع هنا" /
  "لا يوجد موردين").
- سطر وصف رمادي بيشرح السبب أو الاقتراح بلغة واضحة مش تقنية ("حدث خطأ
  أثناء محاولة الاتصال بالخادم. برجاء التحقق من اتصالك بالإنترنت").
- زرار CTA واحد برتقالي تحت الوصف: "إعادة المحاولة" للخطأ، أو فعل مباشر
  للفراغ ("تسجيل فاتورة جديدة" / "إضافة مورد جديد").
- **استخدم بالظبط `.error-state` و `.empty-state` الموجودين في
  `components/cards.css`** — ده نفس الشكل ده في كل صفحة، منتلمش نبدله.

## 7. صفحات التفاصيل (تفاصيل فاتورة / تفاصيل مورد)

- رأس: اسم/رقم الفاتورة أو المورد + badge حالة + زرار إغلاق X.
- صف كروت معلومات مصغرة (اسم العميل، رقم الهاتف، العنوان) كل واحدة في
  كارت صغير برأس label رمادي فوق القيمة.
- جدول بنود (منتجات الفاتورة) بنفس ستايل الجدول العادي.
- صفين كروت جنب بعض تحت الجدول (تفاصيل الدفع | تفاصيل الخصم).
- سكشن "العمليات المرتبطة" (مرتجعات/استبدالات) بتابز فوقه.
- زرار "إغلاق" full-width outline في آخر المودال/البانل.

## 8. الألوان الدلالية — خريطة ثابتة

| الحالة/القيمة | اللون |
|---|---|
| نشط / متوفر / مدفوعة بالكامل / نجاح | أخضر `--color-success` |
| غير نشط / نفد / خطأ / حرج / مسترجع | أحمر `--color-danger` |
| منخفض / معلقة / تحتاج انتباه | برتقالي تحذيري `--color-warning` |
| رقم عادي محايد | `--color-text-muted` |

**ممنوع** تستخدم لون التحذير للنجاح أو العكس حتى لو الفرق بسيط بصريًا —
كل صفحة بترجع نفس القيم النصية دي من الـ API فلازم الماپينج يفضل ثابت.

## 9. تفاصيل RTL لازم تتراعى

- الأرقام (SKU، الأسعار، النسب) بتتكتب LTR جوه سياق RTL — استخدم
  `font-variant-numeric: tabular-nums` (موجودة في `.num`) بدل ما تعكس
  اتجاه الرقم نفسه.
- أيقونات الاتجاه (زي سهم "↩" في المرتجعات) لازم تتأكد إنها بصريًا
  منطقية في RTL مش mirror غلط.
- أي `margin-right/left` أو `padding-right/left` **ممنوعة** — استخدم
  `-inline-start` / `-inline-end` بس (موجودة بالفعل في `shell.css`)
  عشان لو يوم اتحول الموقع لـ LTR (نسخة إنجليزي مثلاً) مايتكسرش.

## قبل ما تسلّم أي صفحة جديدة

قارن بعين الصفحة اللي عملتها بأقرب صفحة مرجعية شبهها من الأنماط فوق —
لو فيه فرق في الترتيب، الألوان، أو مكان الأزرار، صلّحه قبل ما تعتبر
الشغل خلص. الهدف: حد يفتح الصفحة بتاعتك جنب صورة الفيجما ميلاقيش فرق.
