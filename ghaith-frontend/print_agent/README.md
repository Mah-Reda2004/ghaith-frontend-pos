# Ghaith Print Agent

وكيل طباعة محلي لنظام غيث يعمل على `127.0.0.1:17891` دون نافذة طباعة المتصفح.

- الفاتورة الحرارية 80mm تُطبع مرة بأوامر ESC/POS مباشرة، لمنع طباعة بيانات تعريف Windows كرموز أو ورق زائد في الطابعات مزدوجة الوضع.
- الباركود 40×23mm يُطبع في منتصف الاستيكر على الطابعة المختارة بعدد كمية المنتج (`copies`).
- من صفحة الإعدادات يمكن توجيه تعريف Windows نفسه للإيصالات والليبل معًا، وهو مفيد لطابعات XP-Q371U ثنائية الوضع.
- يمكن توجيه الإيصالات والليبل إلى تعريف Windows نفسه لطابعة XP-Q371U مزدوجة الوضع؛ بدّل وضع الطابعة حسب نوع الورق المطلوب.
- صفحة الإعدادات تعرض منفذ USB وحالة تعريف Windows وعدد أوامر الطباعة المعلقة لكل تعريف لتوضيح أخطاء قائمة الطباعة.
- نجاح الإيصال ينتظر نتيجة وكيل الطباعة؛ حالة المهمة متاحة عبر `GET /api/job-status/{job_id}`، ولا يُعرض قبول الطابور على أنه اكتمال.
- عند عدم وجود طابعة تُحفظ معاينة PNG داخل `%LOCALAPPDATA%\GhaithPrintAgent\previews` في نسخة EXE، أو داخل `print_agent\previews` أثناء التطوير.
- صفحة الإعدادات: `http://127.0.0.1:17891`.

## البناء والتثبيت

1. شغّل `build-exe.ps1`.
2. شغّل `install-startup.ps1` لتثبيت النسخة وإنشاء اختصار مخفي داخل Startup وتشغيلها مع بدء Windows.

## API

- `GET /health`
- `GET /api/printers`
- `GET /api/settings` / `POST /api/settings`
- `POST /api/print/receipt`
- `POST /api/print/barcode`
- `GET /api/job-status/{job_id}`

طلبات الطباعة تستخدم `X-Ghaith-Print-Key: ghaith-local-print-v1`.
